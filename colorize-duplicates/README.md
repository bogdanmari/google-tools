# Colorize Duplicates

## Description

Highlights duplicate non-empty values in the selected Google Sheets range. Each duplicated value is assigned a background color so matching cells are easy to identify.

## How to Use

Open a Google Sheet, go to **Extensions → Apps Script**, paste the contents of `colorize-duplicates.gs`, and save the project. Select the range you want to check, then run `colorizeDuplicates` from the Apps Script editor and grant the requested permissions.
