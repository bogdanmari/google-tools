# Colorize Duplicates

## Description

Highlights duplicate non-empty values in the selected Google Sheets range. Each duplicated value is assigned a background color so matching cells are easy to identify.

When processing is complete, the script displays a message showing how many unique duplicate values were found.

## Installation

1. Open a Google Sheet and select **Extensions → Apps Script**.
2. Paste the contents of `colorize-duplicates.gs` into the editor.
3. Save the project.
4. Reload the spreadsheet to add the custom menu.

## Usage

1. Select the range you want to check.
2. In the spreadsheet menu, select **bogdanmari-scripts → Colorize Duplicates**.
3. Grant the requested permissions when running the script for the first time.
4. Wait for the completion message.
