# Convert RGB to HEX

## Description

Adds a custom Google Sheets function that converts an RGB string containing three values from 0 to 255 into a hexadecimal color code.

## How to Use

Open a Google Sheet, go to **Extensions → Apps Script**, paste the contents of `convert-RGB-to-HEX.gs`, and save the project. In a cell, enter a formula such as `=ConvertRGBtoHEX("255, 128, 0")` or reference a cell containing the RGB value, for example `=ConvertRGBtoHEX(A1)`.
